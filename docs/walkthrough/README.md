# Walkthrough

Block-by-block explanations of the real code, one module at a time, written for
someone who can program but doesn't know this stack. Each page covers what a
piece does, why it is written that way, what the alternative was, and the
industry name for the technique.

Read in order: each page builds on the previous ones. Every page ends with a glossary and questions to check your understanding.
